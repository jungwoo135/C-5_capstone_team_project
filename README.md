# '신중: 신뢰가는 중고거래' 프로젝트

AI 기술을 활용하여 기존 중고거래의 사기 위험을 줄이고,
상품 검색 및 등록 편의성을 개선하는 모바일 애플리케이션입니다.

## 프로젝트 목표

- 안전하고 신뢰할 수 있는 중고거래 환경 제공
- AI 기반 상품 검색 편의성 향상
- AI를 활용한 상품 등록 과정 간소화
- 상품 검증 결과를 통한 거래 신뢰도 향상

## 주요 기능

### 1. 벡터 이미지 검색
상품 이미지를 업로드하면 벡터 유사도 기반으로
비슷한 상품을 검색합니다.

### 2. 상품 정보 자동 추천
AI가 상품 이미지를 분석하여 상품명, 카테고리,
설명 등의 기본 정보를 추천합니다.

### 3. AI 인증 마크
AI가 사전에 정의된 검증 기준에 따라 상품 정보를
평가하고, 결과에 따라 인증 마크를 표시합니다.

## 4. 안전 장소 추천
공공 데이터를 기반으로 AI가
주변의 안전 거래 장소를 추천합니다.

## 기술 스택

- Frontend: React Native, JavaScript
- Backend: JAVA
- AI: 추후 확정
- Collaboration: GitHub, GitHub Projects
