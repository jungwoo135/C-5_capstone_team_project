# '신중: 신뢰가는 중고거래' 프로젝트

## 프로젝트 목표

- 안전하고 신뢰할 수 있는 중고거래 환경 제공
- AI 기반 상품 검색 편의성 향상
- AI를 활용한 상품 등록 과정 간소화
- 상품 검증 결과를 통한 거래 신뢰도 향상

## 주요 기능

- 기본 정보(제목, 설명, 시세 등) 자동 추천
- 벡터 기반 이미지 검색
- AI 분석을 통한 사기 방지
- 공공데이터 기반 안전장소 추천

## 기술 스택

- Frontend: React Native, JavaScript
- Backend: JAVA
- AI: 추후 확정
- Collaboration: GitHub, GitHub Projects

## 팀 구성

| 이름 | 역할 | 담당 업무 |
|------|------|-----------|
| 김정우 | 팀장 / Frontend | UI/UX, React Native, 일정 관리 |
| 박준혁 | Backend | 서버, 데이터베이스, API |
| 김영재 | UI디자인 |  |

## 디렉터리 구조

- frontend/: React Native 애플리케이션
- backend/: 백엔드 서버
- ai/: AI 모델 및 서비스
- docs/: 프로젝트 문서

## 협업 규칙

- main: 안정적인 코드 관리
- develop: 기능 통합
- feature/*: 개별 기능 개발
- 새로운 기능은 Issue를 등록한 뒤 개발
- Pull Request를 통해 코드 병합
